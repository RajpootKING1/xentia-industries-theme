## 🏛️ Theme Architecture & Specifications

This theme is structured natively for Shopify Online Store 2.0 with full JSON template support, modular Liquid sections, accessible design system tokens, and native mobile navigation.

* **Layout:** `layout/theme.liquid`
* **JSON Templates:** `templates/index.json`, `templates/cart.liquid`, `templates/collection.liquid`, `templates/product.liquid`, etc.
* **Institutional Pages:**
  * Turnkey B2B RFQ Quotation (`templates/page.wholesale.liquid`)
  * Hospital & Institutional Customer Portal (`templates/customers/`)
  * Sialkot Metallurgy & Heritage (`templates/page.about.liquid`)
  * Technical Factory Desk & WhatsApp Integration (`templates/page.contact.liquid`)
  * Procurement FAQ Accordions (`templates/page.faq.liquid`)
  * Compliance, Lifetime Warranty & Incoterms 2020 (`templates/page.policies.liquid`)
* **Sections:** 13 customizable sections for the Shopify Theme Customizer.
* **Snippets:** Product cards, metallurgy badges, social handles, and cart drawer.

## 🚀 Connecting to Shopify via GitHub

1. In **Shopify Admin**, navigate to: **Online Store** &rarr; **Themes**.
2. Under **Theme library**, click **Add theme** &rarr; **Connect from GitHub**.
3. Select this repository: `RajpootKING1/xentia-industries-theme`.
4. Select the branch: `main`.
5. Click **Connect theme**.

Any changes pushed to `main` will automatically deploy live to Shopify!
